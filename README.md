# CTU Danao Lost & Found

A web-based Lost and Found system for Cebu Technological University — Danao Campus.

## Tech Stack
- PHP
- MySQL
- Bootstrap 5
- JavaScript

## Setup
1. Clone the repo into `htdocs/`
2. Import `database.sql` in phpMyAdmin
3. Copy `config/db.example.php` to `config/db.php` and fill in your credentials
4. Place project images inside `uploads/`
5. Visit `http://localhost/ctu-lost-found`
